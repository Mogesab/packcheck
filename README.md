# Tech Picks USA — free affiliate site

## Before publishing
1. Your Amazon.com Associates tracking ID is already set to `matechreviews-20` in `script.js`. This updates every Amazon link.
2. Keep the disclosure text visible. Amazon requires the wording: “As an Amazon Associate I earn from qualifying purchases.”
3. Do not add copied Amazon product photos, prices, ratings, or claims manually. Use Amazon's approved linking/content tools when you need product-specific content.

## Publish free with GitHub Pages
1. Create a free GitHub account at github.com.
2. Create a new public repository named `techpicks-usa`.
3. Upload all files in this folder to the repository's top level.
4. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`. Save.
5. GitHub shows your free public address in the Pages settings, normally `https://YOUR-USERNAME.github.io/techpicks-usa/`.
6. Add that exact public address to your Amazon Associates account under the websites/apps you use to promote links.

## Pinterest plan
Create one pin for each page section, using a helpful angle such as “7 simple home-office upgrades.” Link pins to your website guide or the homepage—not directly to every Amazon product. Add a clear affiliate disclosure when required. Publish helpful short posts consistently; a website needs useful pages indexed by Google before it can build steady search traffic.

## Important
This site names real product models but uses Amazon *search* links instead of a fixed product page. That lets visitors compare current sellers, configurations, stock, and prices. Do not claim a product is the “best,” or copy Amazon prices, ratings, or images, without keeping that information current and using Amazon-approved content tools. Review the current Amazon Associates agreement and your local legal/privacy requirements before publishing.
